### ✨ Features

- `options.blockEditor` turns the WYSIWYG renderer into a page edited block by block, Notion
  style: a gutter handle on every top-level block (`+` inserts a block below and opens the `/`
  palette, the grip drags the block or opens its menu: turn into, clear formatting, duplicate,
  copy text, move up/down, delete), a hint on the empty block holding the cursor, no fixed
  toolbar and no border. The bubble menu and `/` palette turn on unless set explicitly, and
  `dragHandle`, `placeholders` and `bordered` tune the mode. No node type is added, so stored
  `json`, `html` and `markdown` values are unchanged. The handle is built on ProseMirror alone:
  unlike Nuxt UI's `UEditorDragHandle`, it needs no `@tiptap/y-tiptap`, `yjs` or `y-protocols`.
- `buildWysiwygBlockMenu`, `runWysiwygBlockAction`, `createWysiwygBlockPlaceholder`,
  `findWysiwygBlockAt`, `insertWysiwygBlockAfter` and `resolveWysiwygBlockEditor` are exported
  from `/advanced` for custom editors.

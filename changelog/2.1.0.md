### ✨ Features

- WYSIWYG renderer: tables, task lists, alignment, colors, highlights, link panel, find & replace,
  source mode, preview, an opt-in text bubble and an opt-in slash palette (`0de8d92`).
- Optional AI writing assistant over a host AI SDK endpoint (UI message stream, text stream or
  JSON); results stay in a detached panel until accepted, requests are abortable and the feature
  is inert unless `ai.enabled` is `true` (`0de8d92`).
- `options.contentType: 'markdown'` stores the WYSIWYG value as a Markdown string through TipTap's
  Markdown extension; source mode edits the raw Markdown and the builder inspector offers the
  Markdown format (`string` schema).

### 🐛 Fixes

- The `@nuxt/ui` peer dependency now requires `^4.10`: the rating control imports `UInputRating`,
  which first shipped in Nuxt UI 4.10.0, so hosts on 4.8 or 4.9 failed to build.

### ⚠️ Behavior changes

- `options.api` (autocomplete) sends no request without a host policy in JSON Forms
  `config.apiPolicy`: list `'self'` and/or exact origins in `allowedOrigins`, or resolve requests
  with `resolve`. Redirects are refused and UI schemas only send CORS-safelisted headers unless
  `allowedHeaders` says otherwise (`b07990b`, `7b29970`).
- `Categorization` keeps the active category in memory and no longer writes `#tab=…` into the page
  URL; `options.urlHash: true` restores the hash sync (`d48221b`).
- `<FormBuilder>` persists no draft by default; `:storage-key="true"` restores the historical
  `localStorage` key, or pass your own key (`a832c2f`).
- A new `date-time` value without custom `pattern` is written with the browser's offset
  (`…T10:30:00+01:00`), as JSON Forms does; `options.dateTimeOffset: 'none'` keeps naive values
  (`39c8fea`).
- `createJsonFormsTranslator({ locale })` now also returns the library's interface texts: an
  English locale shows English buttons, confirmations and pickers. Without a `locale`, or without a
  translator, the texts stay in French (`d3f3340`).

### ✨ Features

- Every interface text (arrays, confirmations, pickers, upload, WYSIWYG, AI assistant, builder)
  goes through the JSON Forms translator under `jsonformsBuilder.*` keys, with French and English
  catalogs (`UI_MESSAGES`); host `messages` override any text, calendars follow
  `jsonformsBuilder.locale`, and `<FormBuilder>` takes `locale` and `translate` props
  (`d3f3340`).
- Entry points `@ficsysfr/jsonforms_builder/core` (renderers without any Tiptap import),
  `/advanced` (WYSIWYG, `allRenderers`), `/builder` and `/icons`, with `"sideEffects": false`; the
  root keeps re-exporting everything. A page on `/core` drops from 591 kB to 387 kB gzipped
  (`99cdf5e`).
- `strictCspRenderers`: the core renderers that run under a CSP without `'unsafe-inline'`,
  `'unsafe-eval'`, `data:` or `blob:` (file upload left out), with a documented recipe
  (`9c7ad17`, `4680af1`).
- Published icon lists `CONTROL_ICONS`, `WYSIWYG_ICONS`, `BUILDER_ICONS` and `LIBRARY_ICONS`, from
  a dependency-free `./icons` entry importable in `nuxt.config` (`e9df6ba`).
- Host policy for `options.api`: `resolve`, `allowedOrigins` (`'self'` for the page origin),
  `credentials` and `allowedHeaders` (`b07990b`, `7b29970`).
- `useUiControl` exposes `isLocked`, `localErrors` and `serverErrors` for custom renderers
  (`a9a3caa`, `7045f69`).

### 🐛 Fixes

- Read-only mode is honoured by every control: checkbox, switch, radio group, select menus,
  autocomplete, multi-enum and the `oneOf` variant selector stayed editable; JSON Forms 3.8's
  separate `readonly` state (READONLY rules, `config.separateReadonlyFromDisabled`) now locks
  controls and reaches nested renderers (`a9a3caa`).
- Errors supplied through `additional-errors` are kept apart from local validation errors and stay
  visible before the first touch; `enableFilterErrorsBeforeTouch` now also hides the message,
  not only the color, and a change counts as a touch (`7045f69`).
- A `oneOf` of constants (`[{ const, title }]`) renders as a searchable select instead of a
  combinator with one sub-form per constant (`248a6b7`).
- RFC 3339 `date-time` values with an offset (`+05:30`, `Z`) were shown empty and lost their
  offset when edited; the wall time is now shown with a `UTC±HH:mm` hint and written back with its
  offset (`39c8fea`).
- `oneOf`/`anyOf` renderers no longer compile every variant with Ajv on each render, which a CSP
  without `'unsafe-eval'` refused (`4680af1`).
- A relative `options.api.url` without `base` resolves against the page instead of throwing
  (`b07990b`).
- The WYSIWYG renderer's imports of `@tiptap/core`, `pm`, `vue-3` and `extension-image` are
  declared as optional `^3.30.5` peers, so strict installers can resolve them (`3baad2c`).

- Tiptap floor raised to `^3.30.5`, every `@tiptap` and `prosemirror` package relocked on one
  version (`1123073`).
- `radash` (unpublished since 2025-06-18) replaced by internal helpers with the same contracts
  (`7fca010`).
- CI matrix: Nuxt UI 4.10 and 4.12 × TypeScript 5.9 and 6.0, each cell running type-check, build,
  unit tests and the Chromium recipe (strict CSP, read-only, server errors, `./core` without
  Tiptap) (`a8096e8`, `9c7ad17`).
- The package audit checks entry points, `sideEffects` and that every runtime import of `src` is
  declared (`99cdf5e`, `3baad2c`); size budgets raised to 900 kB packed and 4.25 MB unpacked for
  the per-entry chunks and the two catalogs (`4eb690a`).
- The Chromium recipe also renders the form in English (`d3f3340`).

### ⚠️ Breaking Changes

- Official v2 packages move to `@ficsysfr/jsonforms_builder` and
  `@ficsysfr/jsonforms_builder-mcp`. Public exports, the MCP binary name and the historical builder
  draft key stay unchanged; only installation and import paths change.

### 🐛 Fixes

- Added blocking TypeScript validation and corrected TipTap `NodeView`, invalid UI-schema input,
  JSON Schema `allOf` accumulation and non-textual date-format handling (`aca301d`).

### 📝 Documentation

- Moved canonical repository, Pages, Codecov and contributor links to FicSysFR (`8922fb4`).
- Updated installation, Tailwind, Vite and MCP examples for the `@ficsysfr` scope.

### 🔧 Internal

- Added audited npm tarballs, checksums, versioned changelog sources and one idempotent release
  workflow using npm Trusted Publishing provenance.
- The one-use bootstrap run freezes the former `@tacxou` v2 packages only after both FicSysFR
  packages have passed registry integrity and dist-tag verification.

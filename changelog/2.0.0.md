Complete stack change: the renderers no longer build on Quasar but on
**Nuxt UI 4 + Tailwind CSS 4**, and therefore inherit the host application's theme automatically.

### ⚠️ Breaking Changes

- Renderers rewritten on the Nuxt UI `U*` components: `nuxtUiRenderers` and `allRenderers` replace
  the Quasar entry points (`c3a864d`).
- `@nuxt/ui` becomes a peer dependency alongside Vue and JSON Forms (`c3a864d`).
- Tailwind 4 consumers must include the package's `dist` directory as a source (`c3a864d`).
- v1 remains available from the `v1-quasar` branch and `@tacxou/jsonforms_builder@1.x`.

### ✨ Features

- Added the visual schema/UI-schema builder with draft persistence and JSON export (`b7deded`,
  `586c236`).
- Added PIN, color, file upload, rating, calendar, tags, slider and rich-text controls.
- Added date ranges, configurable icons, `clearOnHide`, `allOf` handling and richer array support.

### 🐛 Fixes

- Preserved partially typed years and object data, blocked self-referencing schema recursion and
  avoided stale menu listeners during subtree unmounts.

### ⚡ Performance

- Reduced object renderer work and optimized deep `allOf` flattening.

### 📝 Documentation

- Added the VitePress documentation, embedded playground and detailed integration guides.

### 🔧 Internal

- Migrated from Bun to Yarn Classic, replaced ESLint/Prettier with Biome and split regression and
  performance test suites.
